# Відкат

Три незалежні рівні. Кожен повертається окремо, у будь-якому порядку.

## 1. Фронтенд (сторінка на GitHub Pages)

Зміни лежать у гілці `claude/app-db-logging-issue-5cq1rb`.
**Доки її не злито в `main`, живий сайт працює на старій версії** — відкочувати нічого.

Якщо вже злито і треба повернути:

```bash
git checkout main
git checkout <SHA-коміту-до-змін> -- Detergents_and_disinfectants.html
git commit -m "Відкат Detergents_and_disinfectants.html"
git push origin main
```

Базовий коміт до змін: **`b559eb1`**. Тобто:

```bash
git checkout b559eb1 -- Detergents_and_disinfectants.html
```

GitHub Pages перебудується сам за хвилину-дві.

## 2. Бекенд (Apps Script)

Старий код нікуди не подівся — він лишається окремою версією розгортання.

Розгортання → **Керування розгортаннями** → олівець ✏️ →
у полі «Версія» вибрати **попередню** (на 31.08.2026 це «Версія 6 від 18 травня 2026 р.»)
→ Розгорнути.

**URL не змінюється**, застосунок одразу починає працювати зі старим кодом.
Правити `GOOGLE_SCRIPT_URL` не треба.

## 3. Дані в таблиці

Нова версія **нічого не видаляє**. Вона лише додає:

| Що додається | Як прибрати |
|---|---|
| Аркуш **«Журнал_подій»** | Видалити аркуш. На облік не впливає — це діагностика. |
| Колонка **O «Місце зберігання»** на аркушах засобів | Видалити колонку O. |
| Рядки «Зміна місця» в «Лог_використання» | Видалити рядки. У розрахунку залишку вони не беруть участі. |
| Властивість скрипта `thresholdNotices` | Налаштування проєкту → Властивості скрипта → видалити. |

Єдине, що змінюється **необоротно** — колонка **E «Поточний залишок»**:
нова версія перераховує її з журналу. Тому:

- перед розгортанням зробіть **копію таблиці** (README, крок 1);
- запустіть `auditStockDrift()` — він друкує, які саме значення зміняться,
  ще до того, як щось буде записано;
- якщо перерахунок небажаний, поставте в `Code.gs`
  `RECOMPUTE_STOCK_FROM_LOG = false` — залишок рахуватиметься по-старому
  (інкрементом), але захист від одночасних записів (`LockService`) залишиться.

## Швидка перевірка після відкату

Відкрити `<URL веб-застосунку>?action=ping`:
- стара версія коду не має дії `ping` і поверне текст `Unknown action` —
  це і є ознака, що відкат до «Версії 6» відбувся.
